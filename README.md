## ⚙️ Investigation Methodology

The documentation across these repositories adheres to standard security operations practices:
* **Scope & Context:** Defining target environments and attack vectors.
* **Evidence & Telemetry:** Captured event logs, CLI outputs, and sandbox behaviors.
* **Artifact Extraction:** Extracted IOCs, hashes, and event IDs.
* **Remediation:** Actionable hardening, mitigation, and detection rule design.
